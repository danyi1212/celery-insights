# Celery Insights Helm chart

Deploy Celery Insights against an existing Celery cluster, with a shared SurrealDB instance, optional persistent storage, external database access, and CPU autoscaling.

The [Kubernetes documentation](https://celery-insights.vercel.app/documentation/kubernetes) covers installation, authentication, application configuration, storage, extensions, and upgrades.

For chart development and release checks, see [CONTRIBUTING.md](../../CONTRIBUTING.md#helm-chart-development).
