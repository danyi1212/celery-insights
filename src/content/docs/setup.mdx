Connect a Celery cluster, configure sign-in, then choose how to retain task history.

## Configure the app

Save `config.toml` using your deployment's secret storage:

```toml
schema_version = 1
installation.public_url = "https://insights.example.com"
authentication.mode = "basic"
authentication.session.secret_file = "/run/secrets/insights/session-secret"

[[authentication.accounts]]
username = "admin"
password_file = "/run/secrets/insights/admin-password"
roles = ["administrator"]

[celery]
broker_url = "amqp://user:pass@rabbitmq:5672//"
result_backend = "redis://redis:6379/0"
```

- Generate a shared session secret: `openssl rand -base64 32 | tr '+/' '-_' | tr -d '=\n'`.
- Put the account password and session secret in the referenced files.
- Set up HTTPS ingress for the public URL. Keep port 8555 private and enable WebSocket forwarding.
- For SSO, see [OIDC configuration](/documentation/configuration#openid-connect).

```sh
docker run -p 127.0.0.1:8555:8555 --name celery-insights \
  -v "$PWD/config.toml:/etc/celery-insights/config.toml:ro" \
  -v "$PWD/secrets:/run/secrets/insights:ro" \
  ghcr.io/danyi1212/celery-insights:latest
```

Open your HTTPS public URL and sign in. The default memory database loses history on restart; use [persistent storage or external SurrealDB](/documentation/deployment-patterns) when history must survive.

## Enable Celery events

Apply these settings to the Celery application and restart its workers:

```python
app.conf.worker_send_task_events = True
app.conf.task_send_sent_event = True
app.conf.task_track_started = True
app.conf.result_extended = True
```

The first two provide task events; the last two add started timestamps and result metadata.
